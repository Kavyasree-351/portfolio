# Deploy this portfolio

Repository: https://github.com/Kavyasree-351/portfolio
Website: https://kavyasree-351.github.io/portfolio/

This is a static HTML/CSS/JavaScript site. No build or package installation is needed.

In repository Settings > Pages, choose Deploy from a branch, select main and / (root), and save. GitHub publishes subsequent pushes automatically.

Keep index.html, .nojekyll, favicon.svg, css/, js/, and assets/ at the repository root. Relative asset paths support the /portfolio/ URL.

Edit content in js/content.js and links in js/config.js. Some project and LinkedIn links are placeholders. The included resume is part of the public website.
